**Goal:** Close four v1 SQL-compat gaps: quoted identifier syntax, DROP IF EXISTS variants, column-level PRIMARY KEY uniqueness enforcement, and GROUP_CONCAT aggregate function.

**Tech Stack:** OCaml 5.x, dune 3.x inside podman, menhir parser, alcotest tests.

```ocaml
  | '"' ([^ '"']* as id) '"'  { IDENT id }
  | '`' ([^ '`']* as id) '`'  { IDENT id }
```

## Task 4: GROUP_CONCAT aggregate function

**Files:**
- Modify: `lib/sql/ast.ml`
- Modify: `lib/sql/lexer.mll`
- Modify: `lib/sql/parser.mly`
- Modify: `lib/sql/sema.ml`
- Modify: `lib/sql/exec.ml`

SQLite's `GROUP_CONCAT(col)` concatenates non-null values with `","` separator. `GROUP_CONCAT(col, sep)` uses a custom separator literal. `STRING_AGG(col, sep)` is a SQL-standard alias.

The separator is embedded in the `agg_func` variant as `string option` (None = default `","`, Some s = custom separator), keeping `agg_spec.col_ord` for the column.
