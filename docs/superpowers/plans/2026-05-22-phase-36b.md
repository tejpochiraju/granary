# Phase 36b — WAL + B-tree SAVEPOINT + Recovery Validation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to execute task-by-task.

**Goal:** Land Write-Ahead Log (#75), SAVEPOINT-on-disk (#136), snapshot-isolation + crash-recovery QCheck properties (#32), and a WAL fault-injection harness (#102) — closing all four phase-36b roadmap issues in this branch.

**Architecture:**

- CoW B+-tree already gives free MVCC snapshots; we leverage that for both SAVEPOINT and WAL.
- **SAVEPOINT:** push a stack of `{meta_root, per-tree roots, freelist, n_pages, dirty-clone}` snapshots on the bt_state. `ROLLBACK TO` restores all five fields.
- **WAL:** new `Sqlocaml_storage.Wal` module — append-only frame log (page_id + checksum + 4096-byte page + commit-marker bit). New `Store.open_block` variant that takes a WAL block-device alongside the main one. Reads route through an in-memory wal-index (page_id → latest committed frame index); commits append a batch + commit marker + fsync the WAL only. Checkpointing later writes frames back to the main DB.
- **Recovery:** on open, scan the WAL forward, find the latest contiguous-valid commit batch, build the wal-index from those frames; any partial trailing batch is ignored.
- **Properties:** QCheck `prop_snapshot_iso` + `prop_crash_then_open`. Fault injection extends `Fault_inject` for torn writes on the WAL device and asserts post-recovery integrity.

**Tech Stack:** OCaml 5.x, dune, Lwt, Cstruct, QCheck, existing `Sqlocaml_block.Fault_inject`.

- [ ] **Step 1: Add `dirty_clone` / `dirty_restore` to Pager**

In `lib/storage/pager.mli`:

```ocaml
type dirty_snapshot

(** Snapshot the current dirty set (shallow copy of the page_id -> Cstruct
    mapping; Cstructs themselves are immutable from the pager's view since
    [write] copies them in). *)
val dirty_clone : t -> dirty_snapshot

(** Restore the dirty set from a snapshot. Pages now-dirty but not in the
    snapshot are removed (their content discarded). Pages in the snapshot
    are reinstated. Also restores n_pages and freelist via separate calls. *)
val dirty_restore : t -> dirty_snapshot -> unit
```

In `lib/storage/pager.ml`:

```ocaml
type dirty_snapshot = (int64, Cstruct.t) Hashtbl.t

let dirty_clone t = Hashtbl.copy t.dirty

let dirty_restore t snap =
  Hashtbl.reset t.dirty;
  Hashtbl.iter (fun k v -> Hashtbl.replace t.dirty k v) snap;
  (* Cache is read-cache only — stale entries for now-not-dirty pages will
     be overwritten on next read or are simply harmless. *)
  ()
```

- [ ] **Step 5: Implement `savepoint_rollback` (Btree)**

```ocaml
| Btree st ->
  let rec find = function
    | [] -> ()
    | sp :: rest when String.equal sp.sp_name name ->
      (* Restore meta-tree *)
      st.meta <- Btree.create st.pager ~root_page:sp.sp_meta_root;
      (* Restore per-tree roots: drop the cache, then re-populate from snap *)
      Hashtbl.clear st.trees;
      List.iter (fun (tid, root) ->
        let bt = Btree.create st.pager ~root_page:root in
        Hashtbl.replace st.trees tid bt
      ) sp.sp_tree_roots;
      (* Restore freelist + n_pages + dirty *)
      Pager.set_freelist st.pager sp.sp_freelist;
      Pager.set_n_pages  st.pager sp.sp_n_pages;
      Pager.dirty_restore st.pager sp.sp_dirty;
      (* Keep the savepoint so ROLLBACK TO can repeat. *)
      st.bt_savepoints <- sp :: rest
    | _ :: rest -> find rest
  in
  find st.bt_savepoints;
  Lwt.return_unit
```

- [ ] **Step 1: WAL frame format**

```
Frame layout (4096 + 24 = 4120 bytes):
  off  0  page_id      uint64  big-endian
  off  8  flags        uint64  bit 0 = commit marker (last frame of a batch)
  off 16  checksum     uint64  XXH64(salt || page_id || flags || page_bytes)
  off 24  page_bytes   4096
```

`lib/storage/wal.mli`:

```ocaml
type t

type frame = {
  frame_idx     : int;          (* 0-based index in WAL *)
  page_id       : int64;
  is_commit     : bool;
  page          : Cstruct.t;    (* 4096 bytes *)
}

val frame_size_bytes : int      (* 4120 *)

type error =
  | Block_error of string
  | Corrupt_frame of int        (* frame_idx that failed checksum *)

val pp_error : Format.formatter -> error -> unit

(** Open a WAL over the given block callbacks. If the file is non-empty,
    scan forward to find the last complete commit batch and pin the WAL
    end to that point (any trailing partial batch is treated as
    nonexistent and will be overwritten by the next append). *)
val open_ :
  read_at  : (offset:int64 -> Cstruct.t -> (unit, string) result Lwt.t) ->
  write_at : (offset:int64 -> Cstruct.t -> (unit, string) result Lwt.t) ->
  sync     : (unit -> (unit, string) result Lwt.t) ->
  size_bytes : int64 ->
  (t, error) result Lwt.t

(** Number of valid committed frames (recovered or appended). *)
val committed_frames : t -> int

(** Most recent committed frame index for [page_id], or None if absent. *)
val find_page : t -> int64 -> int option

(** Read the page bytes at a given frame index. *)
val read_frame : t -> int -> (Cstruct.t, error) result Lwt.t

(** Append a batch of frames; the LAST frame in [pages] is marked as the
    commit frame. Fsyncs after the batch. *)
val append_commit : t -> (int64 * Cstruct.t) list -> (unit, error) result Lwt.t

(** Reset the WAL (called by checkpoint to truncate after migration).
    Sets committed_frames back to 0. *)
val reset : t -> unit
```

- [ ] **Step 2: Implement WAL module**

`lib/storage/wal.ml` — implements the above with an in-memory hashtable
`(int64, int)` for the page-to-frame-index mapping, an `int` for the
committed_frames count, and offset = `frame_idx * frame_size_bytes`.

XXH64 via OCaml: use a simple seeded checksum — FNV-1a 64-bit will do, no need for true XXH64. Salt is 8 random bytes generated at WAL open time when file is empty, persisted at offset 0 of the WAL file (frame_idx = -1 conceptually; subtract from all offset math).

Actually simpler: prepend a 24-byte header (8 magic + 8 salt + 8 ck) at offset 0; frames start at offset 24.

- [ ] **Step 2: Commit through WAL**

In `Store.commit` Btree branch, when `st.wal` is set:
- Skip the existing `Pager.flush` path.
- Collect all dirty pages from the pager: `(page_id, content) list`.
- Add the new header page as the final frame (so recovery picks up the new live state).
- Call `Wal.append_commit`.
- Clear `pager.dirty` since data is durable in WAL.

Note: we deliberately do NOT flush to main DB at commit — that's what `checkpoint` is for (Task 4).

- [ ] **Step 1: `prop_snapshot_iso`**

QCheck generator: random sequence of (put/del) ops. Property:
- Take an RO snapshot before applying.
- Apply ops via RW txn.
- Both before and after commit (mid-txn): RO snapshot reads must match the pre-ops state.

- [ ] **Step 2: `prop_crash_then_open`**

QCheck generator: random sequence of commits. For each commit boundary, store the expected state. Then for each seed:
- Open a fresh WAL-mode store; apply commits 1..k.
- Snapshot WAL/main file bytes.
- Truncate WAL to a random byte offset.
- Reopen.
- Read all keys. Result must equal the expected state at some commit j ∈ [0..k] (i.e., a prefix of commits).
