# Phase 26: Complete PRAGMA Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend PRAGMA support from 2 getters + no-op setter to a full set: `foreign_key_list`, `foreign_keys`, `journal_mode`, `user_version` (getter + persistent setter), and `integrity_check`.

**Architecture:** New `pragma_kind` variants propagate through AST → Sema (pass-through) → Planner (static pragmas resolved from catalog at plan time; `user_version` and `integrity_check` emit new plan nodes) → Exec (new nodes handle RO scan or RW write). `user_version` is persisted as a fixed key in `sys_meta` (tree_id=3). `integrity_check` opens a RO transaction, scans every table and index B-tree, and reports count mismatches.

**Tech Stack:** OCaml 5.x, dune 3.x inside podman, menhir parser, alcotest tests. Build: `podman run --rm -v $(pwd):/workspace:Z -w /workspace sqlocaml-dev dune ...`

### What to add

**`lib/sql/ast.ml`** — replace the `pragma_kind` type:

```ocaml
and pragma_kind =
  | Pragma_table_info       of string   (* PRAGMA table_info(tbl) *)
  | Pragma_index_list       of string   (* PRAGMA index_list(tbl) *)
  | Pragma_foreign_key_list of string   (* PRAGMA foreign_key_list(tbl) *)
  | Pragma_foreign_keys                 (* PRAGMA foreign_keys  → always 1 *)
  | Pragma_user_version                 (* PRAGMA user_version  → read from meta *)
  | Pragma_user_version_set of int64    (* PRAGMA user_version = N → write *)
  | Pragma_journal_mode                 (* PRAGMA journal_mode  → "delete" *)
  | Pragma_integrity_check              (* PRAGMA integrity_check → "ok" or errors *)
  | Pragma_set of string * string       (* fallback no-op setter *)
```

**`lib/sql/parser.mly`** — replace/extend `pragma_stmt`:

```
pragma_stmt:
  (* Arg form: PRAGMA name(arg) *)
  | PRAGMA name = any_ident LPAREN arg = any_ident RPAREN
    { match String.lowercase_ascii name with
      | "table_info"       -> Ast.S_pragma (Ast.Pragma_table_info arg)
      | "index_list"       -> Ast.S_pragma (Ast.Pragma_index_list arg)
      | "foreign_key_list" -> Ast.S_pragma (Ast.Pragma_foreign_key_list arg)
      | _ -> failwith (Printf.sprintf "unknown pragma: %s(%s)" name arg) }

  (* Setter form: PRAGMA name = value *)
  | PRAGMA name = any_ident EQ value = pragma_value
    { match String.lowercase_ascii name with
      | "user_version" ->
        (try Ast.S_pragma (Ast.Pragma_user_version_set (Int64.of_string value))
         with Failure _ ->
           failwith (Printf.sprintf "PRAGMA user_version: expected integer, got %s" value))
      | _ -> Ast.S_pragma (Ast.Pragma_set (name, value)) }

  (* Bare getter form: PRAGMA name *)
  | PRAGMA name = any_ident
    { match String.lowercase_ascii name with
      | "foreign_keys"    -> Ast.S_pragma Ast.Pragma_foreign_keys
      | "user_version"    -> Ast.S_pragma Ast.Pragma_user_version
      | "journal_mode"    -> Ast.S_pragma Ast.Pragma_journal_mode
      | "integrity_check" -> Ast.S_pragma Ast.Pragma_integrity_check
      | _                 -> Ast.S_pragma (Ast.Pragma_set (name, "")) }
```

Keep `pragma_value` rule unchanged (returns string).

**Important:** The bare `PRAGMA name` rule is new. It must come after the other two pragma rules in the `pragma_stmt` production OR be handled carefully to avoid shift/reduce conflicts. In Menhir, these three alternatives are tried in order by lookahead, and since `LPAREN`/`EQ` are distinct from end-of-statement tokens, there should be no conflict.

### 4c: integrity_check (in `to_stream`)

`integrity_check` scans every table and index B-tree in a single RO transaction.

**Algorithm:**
1. Get all tables from catalog (`Cat.list_tables cat`).
2. For each table, open a cursor on `meta.Cat.tree_id`, walk all entries, count rows.
3. For each non-partial index on that table, walk `idx.idx_tree_id`, count entries.
4. If count mismatch: add error string. (Partial indexes may have fewer entries than rows.)
5. If error list empty, return `[["ok"]]`; otherwise return one row per error.

```ocaml
| Plan.Op_pragma_integrity_check ->
  let* tables = Cat.list_tables cat in
  let errors  = ref [] in
  let add_err msg = errors := msg :: !errors in

  let count_entries tx tid =
    let count = ref 0 in
    let* cur  = S.cursor_open tx tid in
    let _     = S.cursor_first cur in
    let rec go () =
      match S.cursor_current cur with
      | None   -> Lwt.return_unit
      | Some _ -> incr count; let* () = S.cursor_next cur in go ()
    in
    let* () = go () in
    S.cursor_close cur;
    Lwt.return !count
  in

  let* tx = S.ro_begin store in
  let* () =
    Lwt_list.iter_s (fun (meta : Cat.table_meta) ->
      let* row_count = count_entries tx meta.Cat.tree_id in
      let idxs = Cat.indexes_for_table cat ~table:meta.Cat.name in
      Lwt_list.iter_s (fun (idx : Cat.index_info) ->
        let is_partial = idx.Cat.idx_where_sql <> None in
        let* idx_count = count_entries tx idx.Cat.idx_tree_id in
        if (not is_partial) && idx_count <> row_count then
          add_err (Printf.sprintf
            "index %s on %s: %d entries != %d rows"
            idx.Cat.idx_name meta.Cat.name idx_count row_count);
        Lwt.return_unit
      ) idxs
    ) tables
  in
  let* () = S.ro_end tx in

  let result = List.rev !errors in
  let rows =
    if result = [] then [ [| Row.V_text "ok" |] ]
    else List.map (fun msg -> [| Row.V_text msg |]) result
  in
  Lwt.return (Lwt_stream.of_list rows)
```

**Note on `S.cursor_close`:** In some versions the close is `unit` not `unit Lwt.t`. Look at how existing cursor patterns close cursors in exec.ml (e.g. `let* () = S.cursor_close cur in` vs `S.cursor_close cur;`). Match the pattern used elsewhere.

**Note on `Cat.list_tables`:** The function signature is `list_tables : Cat.t -> table_meta list Lwt.t`. Pass `cat` (not `store`).

## Known limitations after Phase 26

- `PRAGMA user_version` is only persisted in the Mem backend's in-memory store (same lifetime as the database). Disk backend persistence follows the same sys_meta pattern.
- `integrity_check` verifies B-tree accessibility and index/row count parity but does NOT verify:
  - Individual index key ↔ row value correctness (requires key decoding)
  - FK referential integrity (orphaned child rows)
  - Unique constraint violations in existing data
- `foreign_key_list` `seq` column is always 0 (sqlocaml uses single-column FKs only).
- `PRAGMA journal_mode = wal` is accepted syntactically (falls through to `Pragma_set` no-op) but doesn't change behavior.
