## Task 1: ALTER TABLE ADD COLUMN REFERENCES (FK persistence)

### Background

`ALTER TABLE t ADD COLUMN fk_col INTEGER REFERENCES parent(id)` silently drops the `REFERENCES` clause. The parser correctly populates `col_def.Ast.fk_ref` but two code paths ignore it:

1. `sema.ml` `bind_alter_table` `AA_add_column` arm (~line 2363): never validates parent table/column existence.
2. `exec.ml` `Op_alter_table` `AA_add_column` arm (~line 2952): never reads `col_def.Ast.fk_ref` to persist the FK constraint.

**Key types:**
- `Ast.column_def.fk_ref : (string * string * fk_action * fk_action) option` — `(parent_table, parent_col, on_delete, on_update)`. When `parent_col = ""`, infer the parent table's PRIMARY KEY column.
- `Ast.fk_action` is a type alias to `Cat.fk_action` (see `ast.ml` line 126), so no conversion is needed.
- `Cat.fk_constraint = { fk_local_col; fk_parent_table; fk_parent_col; fk_on_delete; fk_on_update }`.
- `Cat.find_table_cached cat ~name:string : Cat.table_meta option` — synchronous in-memory lookup.
- `Cat.save_fk_constraints cat ~table_name:string ~fks:fk_constraint list : unit Lwt.t` — persists to storage.
- `Cat.set_fk_constraints cat ~table_name:string ~fks:fk_constraint list : unit` — updates in-memory cache (call after `save_fk_constraints`).

## Task 2: INSTEAD OF triggers on views

### Background

`INSERT INTO v …` where `v` is a view currently fails with an error because `Sema.bind` returns a non-`Ok` result (view columns are not writable). INSTEAD OF triggers should intercept this and fire their body instead of failing.

**Key facts from reading the code:**

- `lib/db/db.ml` line 28–34: `trigger_meta.trig_timing` is currently `[ \`Before | \`After ]`.
- `lib/db/db.ml` line 225–236: `trigger_meta_of_ast` has an exhaustive match on `TT_before | TT_after`. Adding `TT_instead_of` will cause a **Warning-8 compile error** if the match is not updated.
- `lib/db/db.ml` line 362–405: `make_trigger_hook` uses the `m.trig_timing = timing` comparison where `timing` is `` `Before `` or `` `After ``. INSTEAD OF triggers use `` `Instead_of `` and will never match, so existing DML hooks are unaffected.
- `lib/db/db.ml` line 411–477: `execute` calls `compile` then dispatches. The INSTEAD OF path needs to intercept the error when `compile` fails for a view target.
- `lib/sql/ast.ml` line 101: `type trigger_timing = TT_before | TT_after`.
- `lib/sql/parser.mly` line 277–279: `trigger_timing` rule has `BEFORE` and `AFTER` only.
- `lib/sql/lexer.mll` line 203–204: `BEFORE` and `AFTER` keywords exist; `INSTEAD` does not.

**Design for INSTEAD OF dispatch:** When `compile t sql` returns `Error (Sema (Unknown_table view_name))` and `Hashtbl.mem t.views view_name` is true, re-parse the SQL and route to `execute_instead_of`. The `Sema.error` type (defined in `sema.ml` line 245) is a plain sum type exposed in `sema.mli`, so pattern matching `Error (Sema (Sql.Sema.Unknown_table view_name))` works directly.

- [ ] **2.6 — Add `execute_instead_of` function to `lib/db/db.ml`**

  Add the following function after `make_trigger_hook` (around line 407) and before `(* ── Public execute / query API ──`)`:

  ```ocaml
  (** Execute an INSTEAD OF trigger sequence for a view write operation.
      [view_name] is the view being targeted.
      [ast] is the parsed write statement (S_insert or S_delete).
      Finds all matching INSTEAD OF triggers and fires their bodies. *)
  let execute_instead_of t view_name ast =
    let find_instead_of event =
      Hashtbl.fold (fun _name trig_ast acc ->
        match trigger_meta_of_ast _name trig_ast with
        | Some m when
            String.equal m.trig_table view_name &&
            m.trig_timing = `Instead_of &&
            m.trig_event = event -> m :: acc
        | _ -> acc
      ) t.triggers []
    in
    (* Helper: turn a simple literal expression into a Row.value.
       Only handles literals (the common case for VALUES rows in INSTEAD OF INSERT). *)
    let eval_insert_ast_value = function
      | Sql.Ast.E_lit (Sql.Ast.L_int n)  -> Row.V_int n
      | Sql.Ast.E_lit (Sql.Ast.L_text s) -> Row.V_text s
      | Sql.Ast.E_lit (Sql.Ast.L_real f) -> Row.V_real f
      | Sql.Ast.E_lit (Sql.Ast.L_blob b) -> Row.V_blob b
      | Sql.Ast.E_lit Sql.Ast.L_null     -> Row.V_null
      | Sql.Ast.E_neg (Sql.Ast.E_lit (Sql.Ast.L_int n)) ->
        Row.V_int (Int64.neg n)
      | _ -> Row.V_null
    in
    match ast with
    | Sql.Ast.S_insert { columns; values; _ } ->
      let matching = find_instead_of `Insert in
      if matching = [] then
        Lwt.return (Error (Sema (Sql.Sema.Unsupported
          (Printf.sprintf "view '%s' is not directly modifiable (no INSTEAD OF INSERT trigger)"
             view_name))))
      else begin
        (* Process each VALUES row *)
        let* () = Lwt_list.iter_s (fun value_exprs ->
          (* Build schema and new_row from columns + values for this row *)
          let schema : Row.column list = List.map (fun col_name ->
            { Row.name = col_name; Row.ty = Row.Text; Row.not_null = false;
  ```

## Task 3: Scalar utility functions (HEX, CHAR, UNICODE, PRINTF/FORMAT, ZEROBLOB)

### Background

Five scalar functions used in real SQL workloads. Pattern is identical to existing functions like `Fn_json_extract`: add variant to `ast.ml`, add keyword to `lexer.mll`, add parser rule to `parser.mly`, add match arm to `exec.ml` `eval_expr`.

**Key implementation details:**
- `HEX(blob)` → uppercase hex. `HEX(text)` → hex of UTF-8 bytes. `HEX(int)` → big-endian int64 hex with leading zeros stripped (SQLite: `HEX(0)` = `'0'`, not `'0000000000000000'`; minimum 1 hex digit, but SQLite actually produces 2 digits minimum for integers — verify: `HEX(0)` = `'00'` in SQLite, `HEX(1)` = `'01'`). Keep at least 2 hex digits for integers to match SQLite.
- `CHAR(...)` → UTF-8 string from Unicode code points. Skip NULL and out-of-range values.
- `UNICODE(s)` → code point of first character; NULL for empty or NULL string.
- `PRINTF(fmt, ...)` / `FORMAT(fmt, ...)` are identical. Support `%d` `%i` `%f` `%e` `%g` `%s` `%q` `%%`. `%q` wraps in single quotes and doubles internal single quotes.
- `ZEROBLOB(n)` → `Bytes.make n '\000'` wrapped in `Row.V_blob`.

**Warning:** The `eval_expr` function in `exec.ml` ends with a catch-all `| _ -> failwith ...` arm (line 819). New Fn_ match arms must be inserted **before** this catch-all, otherwise the compiler will warn about unused patterns.

  ```ocaml
         but keep at least 2 hex digits (to match SQLite: HEX(0) = '00'). *)
      let b = Bytes.create 8 in
      Bytes.set_int64_be b 0 n;
      let hex = Bytes.fold_left (fun acc c ->
        acc ^ Printf.sprintf "%02X" (Char.code c)) "" b in
      (* Strip leading "00" pairs, keep minimum 2 chars *)
      let len = String.length hex in

      while !i < len - 2 && hex.[!i] = '0' && hex.[!i + 1] = '0' do
        i := !i + 2

        match v with

            Buffer.add_char buf (Char.chr (0xC0 lor (cp lsr 6)));
            Buffer.add_char buf (Char.chr (0x80 lor (cp land 0x3F)))

            Buffer.add_char buf (Char.chr (0x80 lor ((cp lsr 6) land 0x3F)));
  ```

## Implementation gotchas

1. **`Ast.fk_action` is a type alias for `Cat.fk_action`**: See `ast.ml` line 126. The declaration is `type fk_action = Sqlocaml_catalog.Catalog.fk_action = FA_no_action | ...`. This means you can use `Cat.FA_cascade` etc. directly in exec.ml when building `Cat.fk_constraint` — no conversion function is needed.

2. **`Cat.save_fk_constraints` signature**: `Cat.save_fk_constraints cat ~table_name:string ~fks:Cat.fk_constraint list` returns `unit Lwt.t`. After `let* () = Cat.save_fk_constraints ...` you must also call `Cat.set_fk_constraints cat ~table_name ~fks` (synchronous) to update the in-memory cache. Both calls are needed (same pattern as `exec.ml` line 2798–2799).

3. **Warning-8 in `trigger_meta_of_ast`**: Adding `TT_instead_of` to `Ast.trigger_timing` immediately causes a Warning-8 compile error in `db.ml` because the match only covers `TT_before` and `TT_after`. You **must** add the `| Sql.Ast.TT_instead_of -> \`Instead_of` arm in the same edit session as step 2.5, or the build will fail.

4. **INSTEAD OF triggers must not fire from `make_trigger_hook`**: The `make_trigger_hook` function (line 362) is called with `~timing:\`Before` or `~timing:\`After`. When `m.trig_timing = \`Instead_of`, the comparison `m.trig_timing = timing` is false, so INSTEAD OF triggers are never accidentally included in the DML before/after hook lists. This is correct behaviour.

5. **`execute_instead_of` must be defined before `execute`**: OCaml is top-to-bottom, so `execute_instead_of` must appear in `db.ml` before the `execute` function that calls it. Place it after `make_trigger_hook` (around line 407).

6. **`execute_instead_of` intercepts only on view names**: The guard `Hashtbl.mem t.views view_name` ensures that a genuine `Unknown_table` error (non-existent table) still returns an error; only genuinely registered views trigger the INSTEAD OF path.

7. **HEX of integer: strip leading zero pairs, keep minimum 2 hex digits**: SQLite strips leading zero *bytes* (pairs of hex digits) but always shows at least one byte. So `HEX(0)` = `'00'`, `HEX(1)` = `'01'`, `HEX(256)` = `'0100'`, `HEX(65536)` = `'010000'`. The stripping loop should advance `i` by 2 characters at a time and stop when `i >= len - 2` (to keep at least 2 chars).

8. **`Fn_char` catch-all pattern**: The `Fn_char, args` arm matches any argument list (including empty). Place it after the specific-arity arms for other functions but before the final `| _ -> failwith` catch-all. OCaml will warn if a pattern is unreachable, so order matters.

9. **`PRINTF` null format string**: If the format argument is not `Row.V_text`, the `| Ast.Fn_printf, _ -> Row.V_null` catch-arm handles it. This is correct SQLite behaviour (NULL format → NULL result).

10. **`Bytes.fold_left` availability**: This function was added in OCaml 4.13. If the build fails with "unbound value Bytes.fold_left", use `Bytes.iter` with a Buffer instead:
    ```ocaml
    let buf = Buffer.create (Bytes.length b * 2) in
    Bytes.iter (fun c -> Buffer.add_string buf (Printf.sprintf "%02X" (Char.code c))) b;
    Row.V_text (Buffer.contents buf)
    ```

11. **`String.fold_left` availability**: Same issue — use `String.iter` with a Buffer if needed.

12. **`Float.to_int` vs `int_of_float`**: Use `int_of_float` for safety as `Float.to_int` raises on out-of-range values in some OCaml versions.

13. **Parser `any_ident` required for contextual keyword use**: `HEX`, `CHAR`, etc. are commonly used as column names or aliases. Adding them to `any_ident` prevents parse failures in `SELECT hex AS hex FROM t` style queries. This is the same pattern used for `REPLACE`, `TRIM`, etc. already in the parser.

14. **Task ordering**: Tasks 1, 2, 3 are fully independent. They touch different files and can be implemented in any order. However, Task 2 adds `TT_instead_of` to `ast.ml` and Task 3 adds `Fn_hex` etc. to `ast.ml` — both changes are additive and do not conflict.
