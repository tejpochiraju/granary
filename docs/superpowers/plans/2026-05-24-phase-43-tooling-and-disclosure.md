### Step B3.1 — Add lint job

- [ ] **Edit `.forgejo/workflows/ci.yml`** — append a new job after `build-and-test`:

```yaml
  lint:
    runs-on: ubuntu-latest
    container:
      image: ocaml/opam:ubuntu-24.04-ocaml-5.1
    steps:
      - uses: actions/checkout@v4

      - name: Install system deps
        run: |
          sudo apt-get update -q
          sudo apt-get install -y -q pkg-config libgmp-dev

      - name: Cache opam packages
        uses: actions/cache@v4
        with:
          path: ~/.opam
          key: opam-5.1-lint-${{ hashFiles('sqlocaml.opam') }}
          restore-keys: opam-5.1-lint-

      - name: Install merlint
        run: opam install -y merlint

      - name: Build (for .cmt files)
        run: opam exec -- dune build

      - name: Run merlint
        run: opam exec -- merlint --bail lib/ test/
```
